# Agent skills

`gpui-kit` and `gpui-kit-design-guides` are copied unchanged from
[longbridge/gpui-kit](https://github.com/longbridge/gpui-kit/tree/v0.9.0/skills)
at tag `v0.9.0`, the version Tabula depends on, under the Apache License 2.0
(`LICENSE-gpui-kit`). Coding agents working in this repository load them
automatically; they hold GPUI Kit's coding and design guides.

When Tabula moves to a newer `gpui-kit`, copy the `skills/` folder from the
matching tag so the APIs they describe match the ones we build against.
